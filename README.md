# YouTube Taller Save Popup

A Chrome extension that improves YouTube's "Save to..." playlist popup:

- **Taller popup** — shows all your playlists (up to the screen height) instead of ~4 at a time.
- **Playlist search** — filter playlists by title as you type.

## Install

1. Open `chrome://extensions` and turn on **Developer mode**.
2. Click **Load unpacked** and select this folder.
3. Refresh any open YouTube tabs.

After editing the code, click the reload icon on the extension's card and refresh YouTube.

## Note
Tweak `MARGIN` in `content.js` at the top to change the gap between the popup and the screen edges.
